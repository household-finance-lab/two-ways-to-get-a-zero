# Project context for Claude

Household Finance Lab, Project 1 — "Two Ways to Get a Zero."

## What this repository is

An exploratory analysis of the 2024 NFCS Investor Survey asking whether, among
respondents with the same number of correct answers on an 11-item investment
knowledge battery, the composition of the remaining responses (wrong vs. "don't
know") is associated with accepting an implausible guaranteed 25% annual return.

Headline: at a fixed number correct, each additional DK in place of a wrong
answer is associated with roughly a 4.7 percentage-point lower probability of
accepting the proposition.

## Ground rules

- **Not peer reviewed, and exploratory.** H1 was formalized after a related
  result was already known. Never describe this study as confirmatory or
  preregistered, and never relabel H1 as prespecified. `ANALYTICAL-DECISIONS.md`
  says so explicitly and must keep saying so.
- **Association, not causation.** Nobody was assigned to say "I don't know."
  Do not write "causes," "leads to," "reduces," or "protects against."
- **No respondent-level data leaves this repository.** The NFCS belongs to the
  FINRA Investor Education Foundation. `.gitignore` blanket-ignores `*.dta`,
  `*.sav`, `*.csv`, and `*.zip`, with a short allowlist for aggregate tables.
  If you add a result file, check it is aggregate before allowlisting it.
- **Revisions stay in the record.** Three interpretations were revised during
  this project and all three are documented. Do not quietly delete a wrong
  turn; document it.

## Layout and run order

```
code/01_build.do                    merge, construct, validate, freeze
code/02_analyze.do                  descriptives, item audit, models, robustness
code/03_nested_prediction.py        nested out-of-sample comparison
code/04_symmetric_comparison.py     symmetric response-composition diagnostic
code/05_nonquiz_dk_sensitivity.py   measurement sensitivity of the auxiliary control
```

Supporting modules: `code/paths.py` (repository-relative paths — all Python
scripts import from it, so no absolute path should ever appear in a script) and
`code/wmnl.py` (weighted multinomial logit with sandwich SEs, the Python
equivalent of Stata's `svy: mlogit`).

Run everything from the repository root. `01_build.do` halts if the
reconstruction drifts from FINRA's published figures; a successful build prints
`VALIDATION GATE PASSED` with a weighted mean correct of 5.33 and an analytic
sample of 2,797.
